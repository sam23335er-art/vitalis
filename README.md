# VITALIS — платформа «Здоровье и Спорт»

Дизайн: чёрный + неоново-зелёный, шрифты Oswald и Inter встроены в сайт (работают без интернета).

Сайт фитнес-клуба с личным кабинетом: React 18 + Vite (фронтенд), Node.js + Express (бэкенд, REST API с CRUD).
**Работает полностью без внешних API, ключей и оплаты.** Два языка: русский и узбекский (кнопка RU / UZ).

## Что умеет

| Раздел | Что делает |
|---|---|
| Главная | Совет дня, калории за день, вода по стаканам, вес и ИМТ, меню и тренировка на сегодня, прогноз «через сколько недель цель», бюджет «сколько останется денег», график веса, серия дней подряд |
| Питание | Календарь на месяц: завтрак, обед, ужин, перекус. Рецепт по шагам, граммы под норму, КБЖУ, цена в сумах, «Съел», замена блюда, своё блюдо, список покупок |
| Тренировки | Расписание на месяц по выбранным дням и цели, отметка «выполнено», свои тренировки |
| ИИ-тренер | Камера → распознавание позы в браузере → считает только правильные повторения (брусья, отжимания, приседания, подтягивания, бицепс), голосовые подсказки |
| Анализы | Сахар, холестерин, гемоглобин и др. → отклонения и диета, «Применить к меню» перестраивает календарь |
| Помощник | Встроенный чат: 55 тем, ответы с личными цифрами пользователя, оценки 👍/👎 |
| Справочник | Вода, изотоники, какую воду пить, сколько сбросить, сроки, режим тренировок, продукты |
| **Обучение ИИ** (админ) | База знаний помощника: добавить/изменить/выключить тему, вопросы без ответа, ответы с 👎, проверка вопроса, экспорт/импорт |
| Админка | Заявки, пользователи, продукты и цены, рецепты |

## Запуск

Нужен только Node.js 20 или 22 (https://nodejs.org, версия LTS).

```bash
npm run install:all
cp backend/.env.example backend/.env      # Windows: copy backend\.env.example backend\.env
npm run build
npm start                                 # открыть http://localhost:5000
```

В терминале появится:

```
VITALIS запущен: http://localhost:5000
Помощник: встроенный, тем в базе знаний — 55 (внешние API не нужны)
Код администратора: 8WBV9HVV
```

## Регистрация и вход

- Пароль — от 8 символов и не простой (не `12345678`, не `qwertyui`). Правила видны прямо под полем.
- Если e-mail уже зарегистрирован, сайт скажет об этом и предложит войти.
- При входе сайт отдельно пишет: «аккаунт не найден» или «неверный пароль».
- **Забыли пароль:** админ открывает Админка → Пользователи → «Сбросить пароль» и передаёт временный пароль. Его потом меняют в Профиле.
- После 10 неверных паролей подряд вход для этого e-mail закрывается на 15 минут (защита от подбора).

## Языки RU / UZ

Переключатель RU / UZ — в шапке сайта, на странице входа и в меню кабинета. Выбор запоминается в браузере.

Переводы лежат в `frontend/scripts/uz/*.py` (ключ — русская фраза, значение — узбекская). Чтобы исправить перевод:

```bash
cd frontend
# поправить фразу в scripts/uz/ui1.py … ui5.py, data.py или server.py
python3 scripts/uz/build.py     # пересобирает src/i18n.uz.js
npm run build
```

Тексты лендинга на узбекском — `backend/data/content.uz.json` (и копия в `frontend/src/data/`).
Ответы помощника и текст «Совета дня» пока только на русском (база знаний одна на оба языка).
Перевод сделан машинно-аккуратно, но перед запуском дай вычитать носителю языка.

## Как стать администратором

1. Зарегистрируйся на сайте.
2. Кабинет → **Профиль** → блок **«Доступ администратора»**.
3. Введи код из терминала (строка «Код администратора»).
4. В меню появятся **«Обучение ИИ»** и **«Админка»**.

Свой код можно задать в `backend/.env`: `ADMIN_CODE=МойСекретныйКод` (минимум 6 символов). Никому его не сообщай.

## Как обучать помощника

Страница **«Обучение ИИ»**:

1. **Без ответа** — вопросы, которые помощник не понял. «Научить» → написать ответ → сохранить. Помощник сразу начнёт отвечать.
2. **Ключевые слова** — начало слова ловит все формы: `похуд` → «похудеть», «похудела». Фразы из нескольких слов ищутся целиком.
3. **Личные цифры** — вставляй в ответ метки `{kcal}`, `{water_rest}`, `{protein}`, `{eta}` и др. — каждый увидит свои значения.
4. **Проверка** — задай вопрос разными словами и посмотри, какая тема выбирается. Не та — добавь ключевых слов.
5. **Не помогло** — ответы, где пользователь нажал 👎. Улучши текст.
6. **Экспорт** — делай копию базы знаний файлом; **Импорт** — загрузить обратно.

## Данные

Всё хранится в `backend/data/db.json`. **Делай копию этого файла регулярно.**
Удалишь его — сайт начнёт с чистой базы (пользователи и обученные ответы пропадут).

## Проверка

`npm test` — 20 автотестов (API, помощник, обучение, код админа, логика ИИ-тренера).

## Перед публикацией в интернете

- Нужен HTTPS — без него браузер не даст доступ к камере.
- Политика обработки персональных данных (Закон РУз № ЗРУ-547); данные об анализах хранить на сервере в Узбекистане.
- Ответы помощника — информационные, не медицинские. Не добавляй в базу диагнозы и дозировки лекарств.
