# Модель распознавания позы (необязательно)

По умолчанию ИИ-тренер скачивает модель с серверов Google при первом запуске.
Чтобы сайт работал без внешних запросов, скачайте файл
https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task
и положите его в эту папку под именем pose_landmarker_lite.task (около 5,5 МБ).
